# Learn B2B Sales Pipeline Analytics with Phoebe

Pipeline analytics from the data side, in ten 45-minute sessions on two tracks.

- **Business (b1-b4, no code):** what a pipeline is evidence of, reading a pipeline review, who
  owns the forecast (the number and the commit vs the method and its error rate), and getting
  from pipeline to plan.
- **Analyst (a1-a6, hands-on in the browser):** the pipeline data model, conversion done
  honestly, velocity and cycle time, three forecast methods, bias and error over many quarters,
  and a forecast honesty bench.

Every widget computes in the browser on real rows of the public Olist marketing funnel dataset
(8,000 leads, 842 won deals; CC BY-NC-SA 4.0, shipped as derived integer arrays). The running
team, Kettle & Co's office-tea arm, and its stages, amounts and reps are constructed.

Static site: open `index.html`, or serve the folder with `python3 -m http.server`.

By Phoebe Fu.
